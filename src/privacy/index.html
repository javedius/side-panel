Space

Privacy Policy

Space extension · version 1.22.0 · updated October 29, 2026

Space is a Chrome sidebar for saved sites, spaces, open tabs, and quick search. This policy describes how the current extension version handles data.

Data Space uses

  • Names, addresses, and order of sites you save; their space assignments; space names and expanded states; sidebar and search engine settings.
  • Titles, addresses, and identifiers of open tabs and windows, used to display tabs, find matches, and switch to an existing tab.
  • Text entered in quick search, used locally to match open tabs and saved sites. When you confirm a web search, it is included in the selected search engine's results URL.
  • Media titles, artist names, playback state, and available playback commands on open sites. Space uses audio/video elements and Media Session to display and control playback. It does not record audio or video.
  • The JSON backup file you explicitly choose to import. Space does not have general access to files on your computer.

Local storage

Saved sites, spaces, settings, and the recovery snapshot before an import are stored in the extension's local Chrome storage on your device. Tab associations and sidebar state also use Chrome session storage. This information supports the extension's interface and is not sent to the developer.

Search query text is not saved in Space's persistent storage. Matching runs locally within the extension. Space does not use Chrome's browsing-history API or maintain its own browsing-history log.

The recovery snapshot remains until a later import replaces it or the extension's data is removed. JSON files you download are stored separately in your browser's download location.

When information leaves your device

When you explicitly run a web search, Space opens a new tab containing your query in the URL of Google, Yandex, Bing, or DuckDuckGo, according to your settings. The search provider receives and processes the query as it would for a regular browser search, under its own policies. Space does not request external search suggestions while you type.

Opening a site makes a normal browser request to that address. Site icons use Chrome's built-in favicon mechanism; Space does not connect to a separate third-party icon service.

The current version has no developer-operated data collection server, advertising or analytics SDK, registration, payment system, or cloud synchronization.

Data use and sharing

Data is used only for the features described above. Space does not sell it, use it for personalized advertising, or send it to the developer for analysis. Data access is limited to the extension's functionality and the actions you initiate.

Space's use of user data complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Your controls and data removal

You can edit or delete saved sites and spaces, change settings, and export your data through the sidebar. Removing an item from the current list does not remove downloaded backup files or the recovery snapshot retained before an import. Remove the extension through Chrome to remove Space's local extension data; delete downloaded backup files separately.

You can hide the site button and change the theme or sidebar mode. Hiding the button does not revoke extension permissions; those are managed in Chrome's extension settings.

Why permissions are needed

Tab access supports the tab list, matching, and switching. Storage saves your sites and settings. The side-panel permission enables Chrome's native sidebar mode. Local script execution on HTTP(S) sites provides the floating sidebar, site button, quick search, and playback controls. Favicon access displays site icons. Browser-internal pages remain subject to Chrome's restrictions.

Contact and changes

For support or privacy questions, use the support section on Space's Chrome Web Store listing. If data-handling practices change, this policy must be updated before releasing that version.
