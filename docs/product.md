# PRD: Space для Chrome
Status: Implemented · Date: 2026-10-21

## 1. Framing
Пользователь: владелец Chrome, которому понравилась панель Zen. Проблема: нужные сайты теряются среди вкладок. Ценность: постоянное место для ссылок. Главная задача: работать с настоящими вкладками из сетки любимых, списка Space и списка обычных вкладок.

## 2. User stories
US-1: Хочу видеть до 9 любимых сайтов. Критерии: три колонки, только занятые ячейки и одна кнопка добавления сразу за ними; при 9 сайтах кнопка скрыта. Пустых строк нет; десятый сайт сохраняется только в Space.
US-2: Хочу хранить менее используемые сайты в Space. Критерии: название и домен; добавление вручную и из текущей вкладки; локальное сохранение.
US-3: Хочу менять свои постоянные сайты. Критерии: общий редактор названия, адреса и раздела; проверка HTTP/HTTPS; удаление с отменой.

US-4: Хочу управлять открытыми вкладками. Критерии: переключение и закрытие; подсветка текущей; список остальных вкладок текущего окна; привязка сайта сохраняется при переходах; закрытие вкладки не удаляет постоянное место.

## 3. User flows
Установка → кнопка расширения → сетка / Space → открытие сайта или активация совпадающей вкладки.
Добавление → название и адрес → раздел → сохранение → обновлённая панель.
Редактирование → сайт → изменение / перенос / удаление → панель.
Пустой Space объясняет добавление. Неверный адрес сохраняет введённые значения. Ошибка хранилища показывает сообщение. Полная сетка предлагает выбрать Space.

## 4. Scope
MVP: панель поверх обычных страниц с нативным резервным вариантом для служебных страниц Chrome, сетка 3×3, Space, редактор, локальное хранение, живой список вкладок и управление ими.
Next: изменение порядка и экспорт резервной копии.
Later: несколько пространств, если одного списка станет мало.
Out of scope: замена интерфейса Chrome и синхронизация аккаунтов. Версия 1.11 добавляет управление медиаплеером открытых сайтов.
Space — постоянные сайты, связанные с живыми вкладками. Версия 1.3 поддерживает несколько именованных пространств с раскрывающимися списками.

## 5. UX & visual brief
Тёмный графитовый интерфейс по референсу. Основной экран и единый модальный редактор. Русские подписи, системные шрифты, цветные инициалы сайтов. Кнопка настройки включает редактирование; одинаковый сценарий для обоих разделов.

## 6. Metrics
Успех: открыть нужный сайт одним нажатием из панели. Контрметрика: сохранённые ссылки не теряются после закрытия. Проверка: установить расширение и пройти добавление, перенос, удаление с отменой и повторное открытие панели.

## 7. Risks & open questions
Chrome управляет расположением и оболочкой панели → инструкция настройки.
Удаление расширения удаляет локальные данные → предупреждение в README; резервные копии в следующей версии.
Разрешение tabs позволяет читать адреса вкладок → использование только локально, без отправки.
После перезапуска Chrome связи восстанавливаются по сохранённым адресам; прочие вкладки остаются в обычном списке.


Обновление 1.2 по запросу пользователя: панель поверх контента без сдвига страницы. Открытие кнопкой расширения; повторное нажатие, × и Escape скрывают панель. Доступ временный, через activeTab/scripting; автоматический перенос панели между страницами не входит в этот вариант. Настройки сайтов сохраняются.


Обновление 1.3: пользователь выбрал список раскрывающихся пространств («Работа», «Личное», «Хобби»). Создание и переименование через общий диалог, добавление в конкретный Space, перенос сайта выбором пространства в редакторе. Сетка любимых общая, несколько списков можно раскрыть одновременно. Существующие сайты мигрируют в первый Space, его ID и связи вкладок сохраняются. Удаление целого пространства не входит в запрос.


Обновление 1.4 по запросу пользователя: открытое состояние панели общее для окна Chrome; панель восстанавливается при переключениях вкладок и загрузке страниц. Закрытие в любой вкладке закрывает её для всего окна. Для этого добавлен постоянный доступ к обычным HTTP/HTTPS-сайтам, взамен модели activeTab. Служебные страницы исключены: при возвращении на обычный сайт наложение восстанавливается. Отдельные окна независимы, содержимое страниц не считывается.


Обновление 1.5: наведение мыши на левый край области сайта (6px, задержка 300мс) открывает панель. Быстрое пересечение, перенос объектов и касания не открывают её по наведению. Нажатие на край и клавиатура доступны как альтернатива. Панель сохраняется при смене вкладок, закрывается явно. Рамка окна и верхняя панель Chrome вне области работы расширения.


Обновление 1.6: по сообщению пользователя наведение не работает; вместо него добавлена видимая кнопка открытия слева по центру сайта с отступом 10px. По уточнению пользователя кнопка уменьшена до 24×28px и полупрозрачна, становится чётче при наведении. Открытие только нажатием; при открытой панели кнопку заменяет сама панель с крестиком. Автоматическое создание кнопки на существующих активных вкладках после обновления, на других — при переключении. Новых разрешений нет.


Обновление 1.7: настройки стороны панели (слева/справа) и кнопки (сверху/центр/снизу) с отступами 10px. Кнопка следует стороне панели. Настройки доступны через отдельную ⚙; выбор сохраняется и применяется ко всем сайтам, включая уже открытые. Отмена не меняет настройки, ошибки сохраняют введённый выбор. Любимые сайты, пространства и открытые вкладки не затрагиваются.


Обновление 1.8: выбор тёмной или светлой темы в ⚙, с сохранением для всех сайтов и окон. Окрашиваются панель, формы, меню, статусы, прокрутка и кнопка открытия. По умолчанию тёмная тема. Настройки положения и сохранённые сайты не меняются. Тема загружается до показа панели, ошибки чтения оставляют доступную тёмную тему.


Обновление 1.9: по просьбе пользователя вся панель больше не прокручивается. Верх с сеткой любимых и нижняя кнопка закреплены; одна внутренняя область прокручивает пространства и вкладки. Формы в диалогах прокручиваются независимо. На низких окнах сетка становится компактнее. Меню сайтов выводятся поверх области прокрутки, чтобы оставаться доступными.


Обновление 1.10: пользователь уточнил, что пространства и вкладки должны прокручиваться отдельно. Сделаны два независимых списка, закреплены их заголовки, сохраняются обе позиции при фоновых обновлениях. Пространства занимают естественную высоту до половины свободной области, вкладки — оставшуюся часть. Убраны декоративный подзаголовок и подпись внизу, чтобы увеличить доступную высоту. Любимые остаются на месте.


Обновление 1.11 по текущему запросу: удаление любого пространства вместе с его сохранёнными сайтами через подтверждение, отмена удаления в течение 12 секунд, открытые вкладки остаются. Допускается удалить последний Space. Любимые занимают только нужные строки, одна ячейка добавления стоит после сайтов, максимум девять сайтов. Кнопка сохранения в подвале удалена, её заменяет компактный плеер открытых вкладок текущего окна. Новый знак — два перекрывающихся пространства. Чтение метаданных и управление HTML audio/video / зарегистрированными Media Session действиями происходят локально, без сети и новых разрешений.


Обновление 1.12: пользователь попросил уменьшить число кнопок и выровнять заголовки/контент. Действия собраны в один ⋯ для панели, каждого пространства и каждой вкладки/сохранённого сайта. Крестик панели остаётся снаружи. Создание Space — компактный + в заголовке. Общие края списков, без вложенных боковых отступов и линий групп, единые размеры иконок и более компактное пустое любимое. Возможности сохранения, редактирования, удаления/отмены и отдельная прокрутка сохранены.


Обновление 1.13: пользователь отверг внешний вид 1.12, предпочёл прежний и уточнил направление «строго, минималистично». Нейтральная палитра вместо зелёных акцентов, менее скруглённые формы, маленькие служебные заголовки, стрелки пространств слева, вторичные действия по наведению/фокусу, плоский плеер с едиными иконками. Возможности и данные не меняются.


Обновление 1.15: пользователь запросил выбор «Поверх сайта / Сдвигать сайт» и включение/выключение кнопки открытия на сайте. Настройки общие и сохраняемые, исходное поведение остаётся по умолчанию. При скрытой кнопке сохраняется открытие значком расширения. Сдвиг следует выбранной стороне, восстанавливает документ после закрытия и не накапливается. На узких окнах используется наложение; режим не является изменением нативного viewport Chrome, поэтому фиксированные блоки отдельных сайтов могут требовать overlay.


Обновление 1.16: по сообщению пользователя custom push не работает. Механизм заменён нативной Chrome sidePanel: веб-область изменяет браузер, скрипт body больше не правит. Выбор стороны для push принадлежит Chrome и объяснён в настройках. Режим поверх сайта, настройки темы и кнопки сохранены. Сокращены подписи положения кнопки без чисел и отступов.


Обновление 1.17: по запросу пользователя добавлено переключение панели клавиатурой. Mac: Cmd+J; Windows/default: Alt+J, чтобы не занять Chrome Downloads Ctrl+J. Это reserved action command, общий с кнопкой расширения. Настройки показывают фактическое назначение Chrome и открывают страницу переназначения; конфликты не скрываются за жёстко указанным хоткеем.


Обновление 1.18: быстрый поиск по Cmd+K на Mac, Alt+K на Windows/Linux. Минималистичная строка по центру страницы, Enter открывает результаты в новой активной вкладке того же окна, Escape/крестик/нажатие снаружи закрывают. Пользователь уточнил: поисковик собственный, из настроек панели. Секция «Поиск» предлагает Google (по умолчанию), Яндекс, Bing и DuckDuckGo. Сочетание отображается фактически назначенное и переназначается через Chrome. На служебных страницах используется небольшое отдельное окно. Запрос не сохраняется и отправляется только после подтверждения; подсказки и история не входят в эту версию.


Обновление 1.19 — поиск и управление сайтами. Источник: пользователь подтвердил все четыре предложенных улучшения, 2026-10-25.

Пользователь: владелец личной панели Chrome. Задача: быстро находить уже открытый или сохранённый сайт и организовывать его без повторного ввода адреса. Существующая компактная строка и спокойный вид панели сохраняются.

US-1. Через ⌘K найти вкладку, любимый сайт или сайт пространства по названию, адресу либо названию Space. При вводе появляется до пяти совпадений; стрелки и Tab дают выбор, Enter/нажатие на результат открывает его. Уже открытый сайт переключает вкладку и окно. Обычный Enter в строке сохраняет поиск через выбранную систему. При закрытом/удалённом результате запрос остаётся доступен и показывается ошибка. Приватные вкладки не смешиваются с обычными.

US-2. Ввести домен или HTTP(S)-адрес и открыть его в новой вкладке. Адрес без схемы получает HTTPS. Обычный текст остаётся запросом. Исполняемые и служебные схемы из произвольного ввода не используются для навигации.

US-3. Перетаскивать любимые сайты для изменения порядка; переносить сайты между любимым и Space либо между пространствами; сохранять открытую вкладку из списка панели в сетку или Space. В любимом максимум девять сайтов; отказ и ошибка записи сохраняют исходное состояние. Перенос в закрытый Space раскрывает его. Открытые вкладки не закрываются. Альтернатива без перетаскивания: «Изменить сайт» с выбором назначения, «Переместить выше/ниже», существующее сохранение вкладки через меню.

US-4. Скачать копию сайтов, пространств и настроек и восстановить её на другом компьютере. В меню панели отдельный пункт «Резервная копия». Импорт показывает файл/количество сайтов и пространств и требует «Заменить данные». Ошибочные файлы не записываются. До записи сохраняются прежние данные, которые можно выбрать в том же диалоге. Открытые вкладки и временные сессии не входят в файл и не изменяются.

Границы первой версии: поиск по вкладкам и данным самой панели, локальные совпадения без внешних подсказок; резервная копия JSON версии 1 до 2 МБ, полная замена с восстановлением предыдущего состояния. Слияние копий, облачная синхронизация и история поисковых запросов в эту поставку не входят. Успех личной проверки: выбранные сайты находятся и открываются без дублирования вкладок; тестовый экспорт/импорт восстанавливает порядок и настройки. Контрметрика: потерянных сайтов/случайно закрытых вкладок нет. Проверка: автоматические сценарии модели/интерфейса плюс ручная проверка в Chrome после обновления; телеметрия не добавляется.
